## 🎯 Configuration Google Ads

### Étape 1 : Créer votre Campagne

1. **Allez sur Google Ads** → Nouvelle campagne
2. **Objectif** : Génération de prospects (leads)
3. **Type de campagne** : Recherche
4. **Paramètres** :
   - Réseau : Recherche Google uniquement
   - Zone géographique : France
   - Langues : Français

### Étape 2 : Structure Recommandée

#### Campagne Auto (Exemple)
```
📁 Campagne : Assurance Auto 2025
  │
  ├─ 📂 Groupe 1 : Auto Paris
  │   Mots-clés :
  │   - [assurance auto paris] (exact)
  │   - "assurance auto pas cher paris" (expression)
  │   - +assurance +auto +devis (large modifié)
  │   URL : /landing/auto?utm_campaign=auto_2025&utm_source=google&utm_medium=cpc
  │
  ├─ 📂 Groupe 2 : Auto Jeune Conducteur
  │   Mots-clés :
  │   - [assurance jeune conducteur] (exact)
  │   - "assurance auto jeune" (expression)
  │   URL : /landing/auto?utm_campaign=auto_jeunes&utm_source=google&utm_medium=cpc
  │
  └─ 📂 Groupe 3 : Auto Malussé
```

## 📊 Tracking des Conversions

### Configuration Google Ads Conversion

1. **Dans Google Ads** → Outils → Conversions → + Nouvelle conversion
2. **Catégorie** : Envoi de formulaire pour prospects
3. **Nom** : Lead Landing Page Auto (adaptez par type)
4. **Valeur** : 150€ (ajustez selon votre LTV)
5. **Période de conversion** : 30 jours

### Événements Déjà Trackés

Les conversions sont automatiquement envoyées à Google Analytics :

```javascript
// Déjà implémenté dans le code
trackEvent('quote_request', {
  category: 'lead_generation',
  insurance_type: 'auto', // change selon la page
  value: 150
});
```

## 🚀 Checklist de Lancement

### Avant de Lancer
- [ ] Vérifier que toutes les landing pages s'affichent correctement
- [ ] Tester le formulaire sur mobile et desktop
- [ ] Vérifier que les emails de confirmation fonctionnent
- [ ] Configurer le tracking de conversion dans Google Ads
- [ ] Préparer 5-10 annonces par groupe d'annonces
- [ ] Ajouter toutes les extensions d'annonce
- [ ] Définir le budget quotidien
- [ ] Ajouter des mots-clés négatifs (gratuit, arnaque, avis, forum...)

### Semaine 1
- [ ] Surveiller les conversions quotidiennes
- [ ] Ajuster les enchères si CPC trop élevé
- [ ] Identifier et exclure les mots-clés non performants
- [ ] Tester 2-3 variantes d'annonces

### Semaine 2-4
- [ ] Analyser les meilleurs mots-clés
- [ ] Augmenter le budget sur les campagnes performantes
- [ ] Créer des audiences de remarketing
- [ ] A/B test sur les landing pages

